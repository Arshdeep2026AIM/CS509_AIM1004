6. BRIEFLY EXPLAIN WHY BLOCKING CAN IMPROVE PERFORMANCE EVEN THOUGH BOTH ALGORITHMS HAVE O(V³) TIME COMPLEXITY.

Answer: Blocking improves performance because it uses the underlying cache memory as the performance boosting method. By doing so, the retrievals of required data (cache hits) increases which is faster compared to fetching data from main memory. Thus even though both implementations have same time complexity, blocking method makes use of cache to optimize performance. However the performance gains are noticeable for larger sizes of matrix(>100,000), and not necessarily for smaller ones.
